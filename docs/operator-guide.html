Hi —

Here's everything you need to run the fire controller on your own. The controller is an M5AtomS3 (small black USB-C box with a button on top). It drives, over DMX, the central propane solenoid (called "Confluence" in the UI) and the 4 towers — each tower has an LED uplight, RGB strips wrapped around the accumulator tank, and its own propane valve.

Important — the Test Fire button is behind a safety cover. On the Test Fire tab there's a big red fire button, but it does nothing until you flip the arm cover toggle above it to "Cover open — armed". The cover re-closes itself every time the page reloads and whenever the controller reboots, so you can't fire by accident just by opening the page. Still keep the gas closed until you're actually ready to test.

1. Powering it on

Plug the controller into USB power (any phone charger or USB battery works). After ~10 seconds it brings up its own WiFi network — there is no internet involved, you're connecting directly to the controller.

2. Connecting to it

On your phone or laptop, join the WiFi network the controller is broadcasting. The SSID and password were set when the firmware was built — they're labeled on the device. There is no internet while you're on this network; that's normal.

On most phones a captive-portal page pops up automatically when you join — that's the config page. If it doesn't, open a browser to http://192.168.4.1.

The captive popup feels cramped? It's a stripped-down browser window. At the bottom of the Test Fire tab there's an "Open in real browser" button — tap it, follow the short instructions (close the popup, open Safari/Chrome, go to http://192.168.4.1), and you'll have the full page in a normal browser tab without dropping WiFi.

3. The config page — tab by tab

The page has tabs across the top: Test Fire · Button Config · Morse · Confluence · Tower Configs. Swipe the tab bar sideways if they don't all fit. Every slider and dropdown saves automatically the moment you release it — no Save button required. Settings persist across power cycles.

Test Fire

Control What it does
Cover open — armed (toggle) The safety cover. Must be ON before the fire button does anything. Resets to OFF (safe) on every page reload and every controller reboot.
Press & hold to fire (red button) Only active when the cover is open. Same as the physical button — tap-and-hold to fire, release to stop (in modes that respect release). Cooldown applies the same as a physical press.
Open in real browser Escapes the captive-portal popup into a normal browser tab (see section 2).

Button Config — fire behaviour

Setting What it does
Mode → FireballPress once → fires for the full Fire duration then stops. Releasing early does nothing; it always runs the full duration.
Mode → PartyFires while held, stops the moment you let go (up to the Fire duration cap). Good for quick blasts of varying length.
Mode → Machine GunWhile held, pulses the solenoids on/off every Machine gun burst milliseconds. Release to stop.
Fire duration (ms)Max time the valves stay open in one trigger. Range 50–10000 ms. Default 3000 ms.
Machine gun burst (ms)Only shown in Machine Gun mode. The on/off time of each pulse. Range 50–2000 ms.
Cooldown (ms)Lockout time between consecutive fires. Range 50–30000 ms. Default 10 s. The button does nothing during cooldown — this is a safety feature, not a bug.
End cueA white flash-and-fade on the tower uplights right after a fire ends. (Drives the uplights' white channel only — it does not open any valve.)

Morse Code

Control What it does
MessageText to send (e.g. SOS). Letters and digits only.
Unit (ms)Base timing unit. Range 50–500 ms; ~150 ms is readable. Dots = 1 unit, dashes = 3, letter gaps = 3, word gaps = 7.
Fire in MorsePlays your message on the central solenoid as dots and dashes. Cooldown is bypassed during Morse — it runs straight through.
StopAborts immediately.

Confluence (the central propane solenoid)

Setting What it does
ConnectedLeave checked to use the central solenoid. Unchecking disables it — useful for dry-run testing without gas, or if you're only firing the per-tower valves.
Fire levelCentral solenoid drive level (DMX channel 4). Range 0–255; 255 is fully open.

Tower Configs

Sub-tabs let you set All towers at once or each tower (0–3) individually. Each sub-tab also prints the DMX addresses to set on that tower's fixtures (decoder and uplight).

Setting What it does
ConnectedUncheck to skip a tower entirely (its lights and valve stay dark/closed).
ThemeThe idle look. Fire gradients (green / blue / fire, flashing), or simon (rotating colours), rainbow, warm white, bright white, candle. White themes use the uplight's dedicated white channel and never open a valve.
BrightnessOverall light level (0–255).
Speed (%)How fast the theme animates (10–400%, 100 = normal).
Flame levelHow far this tower's propane valve opens when firing (0–255). This is the per-tower fire control; it's a separate channel from the lights, so firing never forces the towers white.

Fire vs. white are independent. You can fire while the towers show any colour (no forced white), and you can light the towers white (pick bright white) without opening a valve. The accumulator strips are colour-only and run dimmed to protect the old power supply; the bright white comes from the uplights.

4. The physical button

It's a single button connected to the controller. Press behavior depends on the Mode above. The button does nothing during the cooldown period after a fire — wait the cooldown duration (default 10 s) before pressing again.

5. If something goes wrong

Symptom What to try
No WiFi network appearsUnplug the controller, count to 5, plug it back in. Wait ~10 seconds.
Fire button does nothingCheck the arm cover toggle above it is ON. Could also be in cooldown — wait and retry. If still dead, power-cycle.
Towers don't light upCheck the tower's Connected box and Brightness. Confirm each fixture's DMX address matches the address shown in that tower's sub-tab, and the DMX cable is daisy-chained and terminated.
Firing turns towers whiteA fixture is on the wrong DMX address — the fire valve and white channel are separate; if they overlap, re-check addresses against the sub-tab.
Solenoid won't fire at allOpen the config page, check Confluence → Connected and Fire level (and the tower's Flame level). Confirm gas supply and DMX cabling.
Test Fire works, physical button doesn'tThe physical button or its wiring is the problem, not the controller.
Want to start over from defaultsPower-cycle alone won't reset; settings are saved to flash. Reach out and I can walk you through a config reset.

You don't need a laptop for any of this — a phone in a browser is enough. The page is mobile-friendly.

Have fun and be safe.
