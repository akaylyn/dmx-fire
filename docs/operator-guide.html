Here's everything you need to run the fire controller on your own. The controller is an M5AtomS3 (small black USB-C box with a button on top). In this build it drives only the propane solenoid (called "Confluence" in the UI) over DMX channel 4. No light towers are wired up — ignore any tower-related controls if you see them.

Important — read before opening the page on a phone: The config page has a big red Test Fire button at the top. Tapping it fires the solenoid immediately, with no confirmation. The button reacts to a single touch, so while you're scrolling the page on a phone it's easy to land a finger on it accidentally and trigger a real fire. Scroll from a part of the page that isn't the red button (the white margins on either side, or further down the page), and keep the gas closed until you're ready to test.

1. Powering it on

Plug the controller into USB power (any phone charger or USB battery works). After ~10 seconds it brings up its own WiFi network — there is no internet involved, you're connecting directly to the controller.

2. Connecting to it

On your phone or laptop, join the WiFi network the controller is broadcasting. The SSID and password were set when the firmware was built — they're labeled on the device. There is no internet while you're on this network; that's normal.

Once joined, open a browser to http://192.168.4.1 — that's the controller's config page. On most phones a captive-portal banner will pop up automatically; tapping it opens the same page.

If the page doesn't load, try http://192.168.4.1/ with the trailing slash, or turn WiFi off and back on so the phone re-joins.

3. The config page — section by section

The page is one long form. Every slider and dropdown saves automatically as soon as you release a slider or pick a dropdown option — no Save button required. Settings persist across power cycles.

Test Fire

Control What it does
Press & hold to fire (red button) Same as the physical button. Tap-and-hold to fire, release to stop (in modes that respect release). Cooldown applies the same as a physical press. Use this to sanity-check before a show.

Caution: This button fires on a single touch with no confirmation. When scrolling the page on a phone, scroll from the side margins or from a section below — not from the red button itself, or you'll trigger a fire. Keep the propane closed until you're actually ready to test.

Button Config — the main thing you'll adjust

Setting What it does
Mode → FireballPress once → fires for the full Fire duration then stops. Releasing the button early does nothing; it always runs the full duration.
Mode → PartyFires while held, stops the moment you let go (up to the Fire duration cap). Good for quick blasts of varying length.
Mode → Machine GunWhile held, pulses the solenoid on/off every Machine gun burst milliseconds. Release to stop.
Fire duration (ms)Max time the solenoid stays open in one trigger. Range 50–10000 ms. Default 3000 ms (3 seconds).
Machine gun burst (ms)Only shown in Machine Gun mode. The on-time and off-time of each pulse. Range 50–2000 ms.
Cooldown (ms)Lockout time between consecutive fires. Range 50–30000 ms. Default 10 seconds. The button physically does nothing during cooldown — this is a safety feature, not a bug.
End cueA visual cue meant for towers. Has no effect in this build (no towers wired). Leave at default.

Morse Code

Control What it does
MessageText to send (e.g. SOS). Letters and digits only.
Unit (ms)Base timing unit. Range 50–500 ms; ~150 ms is readable. Dots = 1 unit, dashes = 3 units, spaces between letters = 3 units, spaces between words = 7 units.
Fire in MorsePlays your message on the solenoid as dots and dashes. Cooldown is bypassed during Morse — it runs straight through.
StopAborts immediately.

Confluence (the propane solenoid)

Setting What it does
ConnectedLeave checked. Unchecking disables the solenoid entirely — only useful for dry-run testing without gas.
Fire levelSolenoid drive level on DMX channel 4. Range 0–255. Leave at the value you found it at; 255 is fully open.
The "All Towers" and "Tower 0/1/2/3" sections further down the page are not used in this build. Ignore them.

4. The physical button

It's a single button connected to the controller. Press behavior depends on the Mode above. The button does nothing during the cooldown period after a fire — wait the cooldown duration (default 10 s) before pressing again.

5. If something goes wrong

Symptom What to try
No WiFi network appearsUnplug the controller, count to 5, plug it back in. Wait ~10 seconds.
Button does nothingCould be in cooldown — wait the cooldown duration and try again. If still dead, power-cycle.
Solenoid won't fire at allOpen the config page, check Confluence → Connected is checked and Fire level is non-zero. Confirm gas supply and that the DMX cable to the solenoid is seated.
Test Fire button works, physical button doesn'tThe physical button or its wiring is the problem, not the controller.
Want to start over from defaultsPower-cycle alone won't reset; settings are saved to flash. Reach out and I can walk you through a config reset.

You don't need a laptop for any of this — a phone in a browser is enough. The page is mobile-friendly.

Have fun and be safe.
