Change capture — valve glitches

Every change on a valve channel (1 / 8 / 23 / 38 / 53) is logged with a timestamp. A channel that should be steady — 255 while holding Empty, 0 idle — should log nothing. A burst of changes here, with no button action, is the wire flapping the valve command: the cause of the spurious clicks. Legit button presses show up too (0→255→0), so watch for changes you didn't command.

Channel map mirrors docs/hardware.md. Strips driven to ~75% (old power-limited strips); uplights full. See docs/spec-field-diagnostics.md for the kit and verdict method.
