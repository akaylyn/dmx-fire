Offline fallback for espressif.github.io/esptool-js. Use when the CLI flash can’t connect.

1. Put the device in download mode
  1. Hold the side button on the M5AtomS3.
  2. Unplug + replug USB while holding.
  3. Release the button — the chip is now in ROM bootloader mode.
2. Connect not connected
3. Load firmware binaries
